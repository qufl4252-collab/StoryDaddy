# 동화나라 아이아빠 · StoryDaddy

아빠와 아이가 목소리로 이야기를 이어가고, 매일 새로운 동화를 만나는 웹 서비스입니다.

## 접속 주소

- [사용자 서비스](https://storybook-dad-korea.jojojojo.chatgpt.site) — 실제 기능이 동작하는 공개 사이트
- [GitHub Pages 공유본](https://qufl4252-collab.github.io/StoryDaddy/) — 현재 화면을 간단히 공유하는 미리보기
- [관리자 사이트](https://storybook-dad-admin.jojojojo.chatgpt.site) — 소유자 인증이 필요한 비공개 대시보드

## 준비 중인 기능

- **동화 대화**: 사용자와 음성으로 대화하며 동화를 계속 이어서 들려줍니다.
- **동화 작가**: 매일 새로운 주제의 짧은 동화를 책장처럼 넘겨 읽습니다.
- **관리자 대시보드**: API 연결 상태와 이야기·주제·사용 통계를 관리합니다.

> API 키와 비밀값은 GitHub에 저장하지 않습니다.
